# Правила для изменений в проекте

- Статусы, роли, приоритеты и другие поля с закрытым набором значений объявлять Java `enum`, а не `String`. В JPA сохранять их через `@Enumerated(EnumType.STRING)`.
- Каждый HTTP-маршрут поддерживать в `infra/openapi.yaml` и в контроллере модуля `api`. Для входных DTO использовать Bean Validation (`@Valid`, `@NotBlank`, `@NotNull`, ограничения размера и другие подходящие аннотации).
- До реализации бизнес-операции оставлять явный ответ `501`; не выдавать заглушку за выполненный сценарий.
- Исполняемый Java-модуль только `app-bootstrap`; остальные Maven-модули — библиотеки. Контроллеры находятся в `api`, настройки запуска — в `app-bootstrap/src/main/resources/application.yaml`.
- Локальные настройки и файлы IDE не коммитить.
