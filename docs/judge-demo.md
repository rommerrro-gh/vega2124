# Проверка проекта экспертами

## Внутри MAX: личная демонстрация

Откройте бот организаторов `t802_hakaton_max_bot` в MAX и нажмите «Открыть Пульс дома» в приветственном сообщении. На первой странице мини-приложения введите код демонстрации, выданный командой. Для каждого аккаунта создаётся отдельный тестовый дом и набор примеров внутри отдельного MAX-стенда `https://www.pulsedoma.ru`. У пользователя появляются роли «Житель» и «Диспетчер». Меню ролей свёрнуто в верхней части каждой страницы; там же доступны инструкция, «Начать заново» и «Выйти из демонстрации». Код действует, пока команда не заменит его в конфигурации; число попыток не ограничено.

1. В роли жителя откройте паспорт дома, контакты и опрос.
2. Создайте обращение «Не работает свет в подъезде» с местом «Подъезд 1, этаж 2». Присоединитесь к похожей заявке соседа. Для проверки создания отдельной заявки укажите другую проблему или место.
3. Через верхнее меню перейдите в роль диспетчера, найдите заявку и проведите её до выполнения.
4. Проверьте сообщение бота MAX, вернитесь в роль жителя и подтвердите результат. Можно сначала ответить «Проблема осталась», повторить работу диспетчера и затем подтвердить решение.
5. «Начать заново» создаёт новый тестовый дом для этого аккаунта; «Выйти» отзывает демонстрационные роли. История предыдущей сессии сохраняется для аудита и не показывается через эти роли.

Демонстрация позволяет одному человеку пройти цепочку жителя и диспетчера. Для проверки приглашений и разграничения пяти настоящих ролей, а также доставки уведомлений двум людям, используйте [отдельный порядок проверки](max-staging.md).

## Просмотр всех кабинетов в браузере

Прежний стенд `https://pulsedoma.ru` работает с профилем `demo` и общей тестовой базой. Он показывает интерфейсы пяти ролей без входа: житель, диспетчер, администратор дома, администратор УК и системный администратор. Действия разных экспертов здесь меняют одну базу. Этот стенд нужен для просмотра экранов и не проверяет авторизацию MAX.
