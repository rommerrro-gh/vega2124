# Проверка DATA-API на живом демостенде

30 сентября 2026 года выполнена последовательность из `DATA-API.yaml` на `https://pulsedoma.ru`. Все 22 HTTP-запроса завершились с ожидаемыми кодами. Проверка использовала тестовые роли `X-Demo-Session: true` и `dispatcher`, дом `demo-house-1` и фотографии не загружала.

Проверены ответы и бизнес-состояния: новый `reportId`, новая заявка `DRAFT`, присутствие её ID среди кандидатов дубля, присоединение второго обращения к той же заявке, видимость заявки в очереди диспетчера, установка и перенос даты с двумя записями истории, последовательные статусы, `VERIFICATION_72H` после выполнения, возврат в `REOPENED` после отказа и `CLOSED_CONFIRMED` после повторной работы и подтверждения. Закрытая заявка найдена в списке жителя. Два обращения одного тестового пользователя дают одного участника, поэтому его подтверждение закрывает заявку; подтверждение нескольких разных пользователей этой проверкой не охвачено.

Тестовая заявка: `ba66b136-c1d2-4f87-b244-6de66f221a4b`. Она оставлена закрытой в общей демобазе с описанием, начинающимся с «Проверка DATA-API»; существующие заявки не изменялись.

Эта проверка подтверждает HTTP-сценарий демостенда. Она не проверяет подпись MAX, доставку уведомлений в MAX, загрузку файлов или полную валидацию каждого ответа по JSON Schema. Проверка сценариев в настоящем MAX отдельно подтверждена владельцем проекта.
