# Поиск похожих проблем в основном обращении

Главная кнопка «Сообщить о проблеме» открывает единый сценарий: свободное описание → необязательная тема и место → поиск → явное решение жителя. Получателя и гарантийную квалификацию житель не выбирает. «Не знаю» и неточное место не препятствуют отправке. Уточнение места включается отдельной отметкой; поля и правила переиспользованы из прежнего поиска.

Поиск `/v1/cases/similar-problems` не создаёт report/case. Используется прежний CandidateRetriever: тот же дом, активный статус, окно 30 дней, совместимость места, порог 0.65, максимум десять результатов. Дополнительно ищутся собственные активные PROBLEM/WARRANTY; категория и структурированное место новых обращений сохраняются в case_problem_details. При отсутствии прежних уточнений используется текст и доступное место. Чужие личные обращения и финансовые дела не возвращаются. Фото и документы не распознаются, ИИ не используется.

Результаты ISSUE — общие заявки прежнего процесса, явное присоединение через `/v1/cases/join-problem`. Регистрация report и присоединение выполняются в одной транзакции; clientRequestId защищает повторную отправку и запрещает смену содержания с тем же ключом. Актуальность совпадения повторно проверяется перед присоединением. Пользователь предупреждён о включении его текста и фотографий в общую заявку. Существующий маршрут вложений общей заявки поддерживает JPEG/PNG: при выбранном PDF интерфейс предлагает отдельное обращение либо возврат к редактированию. Вложения загружаются после успешной регистрации, ошибка явно показывается и не скрывает факт присоединения.

Если житель уже участвует в общей заявке, OWN_ISSUE открывает её без повторного сообщения. Результат OWN_CASE открывает собственное обращение без объединения и изменения чужих прав. Отправка отдельного обращения сохраняет новый процесс: первичное рассмотрение, гарантии, визиты, документы и историю. Ошибка поиска отличается от пустого результата: можно повторить или явно продолжить без проверки. Черновик сохраняет описание и уточнения; файлы после перезагрузки выбираются заново.

Приёмка: совпадающий подъезд/этаж; другой подъезд исключён; поиск без записи; присоединение с повтором ключа без дубликатов; отдельное обращение вновь находится; неизвестные тема и место; отсутствие чужих личных и платёжных дел; запрет доступа к чужому дому; обновление V19 → V20 сохраняет исходные данные и не публикует личные сведения. Реальные обращения на публичных стендах для теста не отправляются.
