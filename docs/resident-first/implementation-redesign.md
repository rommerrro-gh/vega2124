# Новый дизайн и городская иллюстрация

23 октября 2026 года выбранный зелёный макет перенесён в приложение. Сохраняются существующие API, права и бизнес-процессы; миграций базы нет.

## Житель

В шапке — упрощённая эмблема, напоминания и меню роли/оформления. Адрес является текстом поверх отдельного WebP, а не частью картинки. Для длинных адресов иллюстрация занимает отдельную правую область. «Сменить дом» использует существующее сохранение активного дома.

Нижняя навигация открывает дом, список обращений и события. Черновик сохраняется при переходах. Главный экран показывает одно актуальное обращение и следующий шаг; полный список и фильтры доступны в «Обращениях». Если API действительно вернул предложение визита, появляется «Выбрать время»; согласованное время выводится только после подтверждения сервером. История не подменяет реальные статусы выдуманными этапами.

Опросы и общедомовые события доступны в «Событиях», тарифы и паспорт — на главном экране. Дополнительное создание похожей заявки и другой вопрос сохранены.

## Оформление

Выбор: «Как в MAX / системе», «Светлое», «Тёмное». Ручная настройка хранится локально; при недоступном хранилище действует до перезагрузки. Автоматический режим использует корректную тему MAX, иначе системную. Цвета MAX UI и собственных компонентов синхронизированы; изменение темы не пересоздаёт форму и не очищает данные.

Общие токены, иконка и более спокойные формы применены также к кабинетам УК, диспетчера, дома, специалистов и получателей материалов. Phosphor Icons 2.1.10 включён в локальный bundle; внешнего CDN нет.

## Иллюстрации

`frontend/src/design-model.mjs` выбирает `kazan-autumn` только при городе Казань в начале адреса; для остальных городов и неизвестного адреса — `universal`. Местоположение устройства не запрашивается. Для каждой сцены есть светлая и тёмная версия в `static/miniapp/art/`.

Для демо в Казани осень закреплена независимо от даты. Автоматической смены по сезону, погоде и времени суток сейчас нет. Другие подготовленные ранее макеты городов остаются концепциями. Иллюстрация — художественный городской образ, не фотография конкретного дома. Генерация при открытии приложения не выполняется.

## Приёмка

- Три теста frontend проверяют выбор сцены, неполный адрес и приоритет ручной/MAX/системной темы: `cd frontend && pnpm test`.
- Maven verify: 192 теста, 0 ошибок/падений, 1 инфраструктурный пропуск.
- Сквозная локальная браузерная проверка: обращение по квитанции, сохранение черновика, визит, навигация, две темы, длинный адрес и универсальная сцена, кабинет УК. Размеры 390×844, 320×740, 1280×900.
- Визуальное сравнение с выбранными макетами: `design-qa.md`.
- После выкладки проверить обе публичные версии, совпадение bundle/иконки/четырёх WebP с коммитом, health и сохранение данных. Не включать рассылки и не переносить учебные записи.
